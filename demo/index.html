About this demo

Seven invented stores, each its own server with its own data. The register in the browser has no gateway, so it takes cash only; the desktop register drives the emulated printers and card terminals. Without a license key every store runs as Starter: one register, and the pizzeria seats only its first three tables. Nothing is kept when the container stops.
